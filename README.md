# 🎬 CineScope

CineScope is a modern movie discovery web application that allows users to search for movies, explore trending titles, and view detailed information such as ratings, release dates, genres, cast, and overviews. It provides a clean, responsive interface for browsing movies using real-time movie data from external APIs.

## ✨ Features

- 🔍 Search for movies by title
- 🎥 Browse trending and popular movies
- ⭐ View IMDb ratings
- 📅 Release date information
- 🎭 Movie genres
- 📝 Movie overview and details
- 🖼️ High-quality movie posters
- 📱 Fully responsive design
- ⚡ Fast and intuitive user interface

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Movie API (OMDb/TMDB)
- Fetch API

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/saicharankollu/cinescope.git
```

### Navigate into the project

```bash
cd cinescope
```

### Open the project

Simply open `index.html` in your browser.

Or use VS Code Live Server for a better development experience.

## 🔑 API Key

If the project uses an API key, create a configuration file and add your key.

Example:

```javascript
const API_KEY = "YOUR_API_KEY";
```

You can obtain a free API key from:

- OMDb API: https://www.omdbapi.com/
- TMDB API: https://developer.themoviedb.org/
